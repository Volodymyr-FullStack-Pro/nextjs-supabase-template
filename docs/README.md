# Документы <Проект>

Карта папки `docs`: где что лежит, онлайн-страницы и люди. Где мы сейчас — только [roadmap.md](roadmap.md), «Сейчас»; здесь статуса нет. Правила жизни документов — `.claude/rules/docs.md`, проверка — `npm run docs:check` (входит в `check` и CI).

## Где что лежит

| Путь                                                                     | Что там                                                                                                                                |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| [roadmap.md](roadmap.md), [blocks/](blocks/)                             | Поставка: «Сейчас», спринты, блоки и задачи; образец файлов блока — [blocks/\_template/](blocks/_template/)                            |
| `plans/`                                                                 | План текущей задачи вне блоков; удаляется, когда задача принята                                                                        |
| [architecture.md](architecture.md)                                       | Как устроена система и почему: действующие решения; правила кода по областям — `.claude/rules/`                                        |
| [glossary.md](glossary.md), [release.md](release.md)                     | Понятия; хостинг и выпуск                                                                                                              |
| [knowledge/requirements.md](knowledge/requirements.md)                   | Реестр требований заказчика: каждый ответ из анкет, переписки и созвонов, трактовка, раздел спецификации, статус                       |
| [knowledge/decisions.md](knowledge/decisions.md), `knowledge/decisions/` | Журнал решений и подробности крупных (`D-NNN.md`), архив заменённых и выполненных                                                      |
| [knowledge/open-questions.md](knowledge/open-questions.md)               | Что ещё не решено и где это спрашивается                                                                                               |
| [design/design-system.md](design/design-system.md)                       | Дизайн-система, выбранная заказчиком                                                                                                   |
| `client/source/`                                                         | Оригиналы заказчика: бриф, ТЗ, файлы, сообщения. Не редактируем                                                                        |
| `client/tz/`                                                             | ТЗ или спецификация для заказчика, прошлые редакции — `archive/`; анкеты и выгрузки ответов — `questionnaires/`                        |
| `client/design-board/`                                                   | Исходники доски с вариантами дизайна                                                                                                   |
| [ops/github/](ops/github/)                                               | Настройки сервисов вне репозитория: защита веток; другой сервис — своя папка `ops/<сервис>/`                                           |
| `src/`, `supabase/`, `tests/`                                            | Код, миграции и тесты — README репозитория                                                                                             |
| `.claude/handoff.md`                                                     | Состояние посреди задачи: пишет `/dev-kit:handoff`, читает `/dev-kit:resume`; их запускает человек, когда Claude предлагает новое окно |

Папка `client/` — всё от заказчика и для заказчика: её файлы Prettier не трогает (`.prettierignore`), а `docs:check` не требует ссылок на них. Папки появляются с первым файлом.
