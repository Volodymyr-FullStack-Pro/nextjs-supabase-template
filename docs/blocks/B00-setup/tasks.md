# B00 Задачи

## [ ] B00-T01 Репозиторий и CI

**Что делаем.** Репозиторий из шаблона в организации заказчика, защита `main` (PR и зелёный CI), оповещения Dependabot, секрет `GITLEAKS_LICENSE` (бесплатный ключ gitleaks для организаций).
**Результат.** Первый PR проходит все проверки CI.
**Как проверить.** PR с этим блоком: все проверки зелёные, прямой push в `main` запрещён.

## [ ] B00-T02 Знания и правила проекта

**Что делаем.** `CLAUDE.md` и `docs/knowledge/` под проект: реестр требований, журнал решений, открытые вопросы; правила работы с заказчиком; `.claude/rules/clickup.md`, если задачи в ClickUp.
**Результат.** Claude в новом окне знает проект, заказчика и правила.
**Как проверить.** `/dev-kit:resume` в новом окне пересказывает проект без пробелов; `npm run req:check` зелёный.

## [ ] B00-T03 Supabase

**Что делаем.** Проекты staging и production, выключенная саморегистрация, `.env.local`, первая миграция, тестовый пользователь (Studio → Authentication) с данными в `.env.local` (`TEST_USER_EMAIL`, `TEST_USER_PASSWORD`).
**Результат.** Локально и на staging работает вход и защищённая страница.
**Как проверить.** `supabase test db` зелёный; вход тестовым пользователем; регистрация нового пользователя недоступна.

## [ ] B00-T04 Vercel

**Что делаем.** Проект Vercel: ветка production — `production`, домен staging — на `main`, переменные окружения для Preview и Production, `CRON_SECRET`, preview на каждый PR (`docs/release.md`).
**Результат.** У каждого PR есть ссылка для показа.
**Как проверить.** В PR появилась ссылка Vercel, по ней открывается приложение.

## [ ] B00-T05 Дизайн-система

**Что делаем.** Выбор заказчика — в `docs/design/design-system.md`, роли — токенами в `src/app/globals.css`, шрифт — `next/font` (скил `dev-kit:design-system`).
**Результат.** Приложение в цветах и шрифте выбранного стиля, обе темы, контраст по таблице.
**Как проверить.** Скриншоты главной на 1440 и 390 в обеих темах; `tests/e2e/ui-quality.spec.ts` зелёный.

## [ ] B00-T06 Безопасность периметра

**Что делаем.** Если приложение закрыто Cloudflare Access — проверка его JWT в `src/proxy.ts` или закрытый `*.vercel.app`; заголовки безопасности проверены на staging.
**Результат.** Без входа через периметр приложение недоступно.
**Как проверить.** Запрос к staging в обход периметра получает отказ.

## [ ] B00-T07 Языки и задачи

**Что делаем.** Если интерфейс на нескольких языках — next-intl со словарями (язык из профиля, без `[locale]`); карточка блока B00 и подзадачи в ClickUp.
**Результат.** Переключение языка работает, тексты — в словарях.
**Как проверить.** Главная на втором языке без обрезанных подписей.
