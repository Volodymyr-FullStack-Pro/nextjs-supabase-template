# Журнал решений

Новые записи — в конец; номер D-NNN не переиспользуется. Статус: **принято** — решено и действует; **предложено** — ждёт подтверждения (указано, где); **заменено D-MMM** — действует другое решение; **выполнено** — разовое действие сделано. Строка — до 40 слов (проверяет `npm run docs:check`); решение, которое меняет архитектуру, стек, процесс, безопасность или деньги, — плюс `decisions/D-NNN.md` по шаблону `decisions/_template.md`: контекст, альтернативы, последствия. Пометка `→ architecture.md` — решение записано в [docs/architecture.md](../architecture.md); действует оно или предложено — по статусу. Строк больше 200 — заменённые и выполненные разовые переносятся в `decisions/archive-<год>-Q<N>.md` (на ретро спринта).
