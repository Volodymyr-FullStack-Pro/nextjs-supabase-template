# Журнал решений

Индекс: одна строка на решение, одно-два предложения. Номер D-NNN не переиспользуется; отменённое решение остаётся со статусом «заменено D-MMM». Решение, которое меняет архитектуру, стек, процесс, безопасность или деньги, получает отдельную запись ADR в `decisions/D-NNN-<тема>.md` (шаблон — `decisions/_template.md`): контекст, альтернативы, последствия. Когда индекс перерастает 100 строк, строки со статусом «заменено» переезжают в `decisions/archive.md`.
