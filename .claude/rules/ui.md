# Интерфейс

- shadcn/ui — в `src/shared/ui` (`npx shadcn@latest add <имя>`); локальные правки вернуть после `add --overwrite`: `field.tsx`, `sonner.tsx`, `card.tsx` (strict TS), `button.tsx` и `input.tsx` (фокус — общий контур 2px из `globals.css` без `outline-none`, hover — `--primary-hover`).
- Форма — по образцу `src/modules/notes/ui/notes-form.tsx`: `useHookFormAction`, поле — `TextField` (`src/shared/ui/form/text-field.tsx`, уже ставит `FieldLabel`, `aria-invalid`, `FieldError`), кнопка — `SubmitButton` (`src/shared/ui/form/submit-button.tsx`) с `pending={action.isPending}`; тексты ошибок — словарь модуля `ui/messages.ts`: `TextField messages={…}` и `toast.error(failureMessage(error.serverError, …))` (`src/shared/ui/form/messages.ts`), а в форме денег ещё и сообщение у самой формы (`role="alert"`): оно остаётся на экране и при отказе сервера, и при потере ответа — `action.hasErrored` без ошибок полей (образец — `notSaved` в `notes-form.tsx`); успех — `toast.success` и `resetFormAndAction`.
- Любая кнопка действия, не только отправка формы, — `disabled` на время `isPending` (`useAction`, `useTransition`). У действия, которое создаёт запись о деньгах или внешнюю операцию, `clientRequestId` (uuid) создаётся в обработчике отправки формы, а не при рендере (`crypto.randomUUID()` при рендере роняет сборку Cache Components), хранится в поле формы до успешного ответа и сбрасывается вместе с формой: повторная отправка после потерянного ответа уходит с тем же ключом и возвращает уже созданную запись. Если данные с тем же ключом отличаются от сохранённых, сервер отказывает: форма показывает у себя, что запись уже сохранена с прежними данными, список обновляется, а ключ сбрасывается — следующая отправка создаёт новую запись (`keepRequestId(form)` в обработчике отправки и `resetRequestId(form)` в `onError` — из `src/shared/ui/form/request-id.ts`; образец — `notes-form.tsx`, `addNote` в `actions.ts`; сторона базы — `.claude/rules/db.md`, «Повторяемая запись»).
- Фильтры, период, выбранный объект — в URL через nuqs: `useQueryState` с `shallow: false` и `limitUrlUpdates: debounce(...)`, loader на сервере (образец — `src/modules/notes/ui/notes-search.tsx`). Глобального стора нет, пока нет доказанной нужды.
- Суммы — `formatMoney(amount, { currency })` из `src/shared/domain/money.ts`: валюта обязательна, значения по умолчанию нет; число знаков берётся у валюты (EUR 2, KRW и JPY 0; код не из ISO 4217, например `USDT`, `BTC`, — число и тикер, до 8 знаков), без явного `fractionDigits` копейки не теряются; символы различают страны (`$`, `CA$`, `CN¥`, `¥`). Ввод — `TextField` с `inputMode="decimal"` и Zod-`transform` через `parseDecimalInput(raw, SCALE.…)` из `src/shared/domain/decimal-input.ts` (без decimal.js — годится для клиентской схемы; целая часть до 16 цифр у фиата, до 2 у доли (`numeric(12,10)`) и до 20 у остальных ролей, дробная по роли: фиат 2, количество, цена и курс до 18, доля 10; тип результата расчётов — `Money` из `money.ts` (`import type` из `decimal.js` тоже запрещён)); образец — поле «Сумма» в `notes-form.tsx` и `CreateNoteInput`. Валюта вводится рядом с суммой: код проверяет `isIsoCurrency` (`src/shared/domain/currency.ts`, без decimal.js — годится для клиентской схемы), а сумму точнее валюты (100,50 для JPY) отклоняет use case через `exceedsCurrencyPrecision` из `money.ts` (образец — `create-note.ts`). Расчёты — только `money()` (клон Decimal с точностью 64 и округлением к чётному), не `new Decimal` из пакета: у глобального класса точность 20 и другое округление. Даты — `formatDate` из `src/shared/domain/time.ts` в `APP_TIME_ZONE`, не в часовом поясе сервера; колонка `date` — `formatDay`.
- Картинка публичной страницы (логотип на `/login`) — импортом файла (`/_next/static/media/…`) или из корня `public/` (`/logo.png`): вложенный путь (`public/images/logo.png`) идёт через proxy, и невошедший получит редирект на `/login` вместо картинки, в том числе через `next/image` (matcher — `.claude/rules/security.md`).
- С next-intl в разметке нет текста, который нельзя перевести; длинный английский не обрезается.
- Таблицы: числа вправо, `tabular-nums`, одинаковое число знаков в колонке, единица (валюта, %) — в заголовке, не в ячейке (в списке с разными валютами — в ячейке, через `formatMoney`); `<caption>` или `aria-label`, `th scope`, `aria-sort` у сортируемых колонок, липкий заголовок у длинных; на телефоне — прокрутка внутри контейнера (`role="region"`, `aria-label`, `tabIndex={0}` — линтер доступности пропускает `tabIndex` только с этой ролью) или карточки; отрицательное — со знаком, не только цветом.
- Новая страница — в `tests/e2e/ui-quality.spec.ts`: публичная в `PUBLIC_PAGES`, за входом в `SIGNED_IN_PAGES` (страницу модуля туда дописывает генератор; пользователь `alice` из setup-проекта `tests/e2e/auth.setup.ts`, `storageState`); страница с данными — ещё и `checkPageQuality` в сценарии модуля, на длинных значениях (`.claude/rules/tests.md`).
- Новая страница — ещё и запись в `MEASURED_PAGES` (`tests/perf/pages.ts`): там же пороги скорости, по ним её меряет `npm run perf` (`.claude/rules/tests.md`). Страница, которую мерить нельзя, — в `NOT_MEASURED` с причиной; без того и другого красный `tests/unit/perf/measured-pages.test.ts`.
- Текст пользователя переносится (`wrap-anywhere`), сумма не обрезается и не рвётся: строка «подпись + сумма» — `flex flex-wrap`, сумма уходит на свою строку (образец — `src/modules/notes/ui/notes-list.tsx`). Контейнер с `overflow-hidden` не прячет содержимое: намеренная обрезка — только `text-overflow: ellipsis`.
- Состояния списка — `docs/design/design-system.md`, «Состояния»: пока данные грузятся, `<Suspense>` показывает скелетон той же формы с `role="status"` и подписью, пустой список говорит, что делать дальше (образец — `…ListSkeleton` и пустое состояние в `ui/__module-name__-list.tsx` шаблона генератора).

Подробно: скилы `dev-kit:design-system`, `dev-kit:performance-budget`, `dev-kit:money-decimal`.
