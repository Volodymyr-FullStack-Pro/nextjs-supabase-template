# Стиль кода

Что можно проверить машиной, проверяет линтер (`eslint.config.mjs`, блок «Стиль кода»): сложность ≤ 10, вложенность ≤ 3, функция ≤ 80 строк, ≤ 3 параметров, без магических чисел, имена без сокращений и одиночных букв, kebab-case файлов. Остальное — правила ниже и ревью.

- **Имена говорят, что внутри.** Функция — глагол (`closeMonth`, `listNotes`), данные — существительное (`note`, `rates`), boolean — `is`/`has`/`can` (`isClosed`), компонент — PascalCase, константа модуля — UPPER_CASE с единицей (`SEARCH_DEBOUNCE_MS`, `NOTE_TITLE_MAX`). Без сокращений (`error`, не `err`; `event`, не `e`; `request`, не `req`), без одиночных букв и цифр в именах. Исключения линтера: `_` (не используется), `z` (zod), `props`, `ref`, `params`, `ctx`, `env`, `db`.
- **Числа и строки — с именем.** Любое число, кроме 0, 1 и индексов, живёт в константе с понятным именем и единицей; строки-коды (`'RULE_VIOLATION'`, теги кэша, имена таблиц) — тоже константы или функции (`notesTag(userId)`).
- **KISS.** Самое простое решение, которое проходит тесты: ранние возвраты вместо вложенных `if`, одна функция — одно действие, объект вместо четырёх параметров, без тернариев в тернариях, без «умных» однострочников. Если функция длиннее экрана — разделить.
- **DRY, но не раньше времени.** Дубли ловит `jscpd` (порог 0 %). Абстракцию заводим на третьем повторе, а не на втором; две похожие функции с разным смыслом — не дубль.
- **YAGNI.** Ничего «на будущее»: нет флагов, параметров и полей без потребителя сегодня; `knip` удаляет мёртвые экспорты; `TODO` только со ссылкой на задачу.
- **TypeScript честный.** Без `any` и `as` (кроме границы с внешними данными — там `unknown` + Zod); `readonly` и `as const` для неизменяемого; `satisfies` вместо аннотации, когда нужен вывод типа; union строковых литералов вместо `enum`; `switch` по union — исчерпывающий.
- **Неизменяемость.** Не мутировать параметры и внешние объекты; `toSorted`, `with`, spread вместо `sort`/`push` на чужих данных.
- **Ошибки.** Ожидаемые — `Result` (`shared/domain/result`), неожиданные — `throw new Error(...)` с сообщением и `{ cause }`; не глотать исключения пустым `catch`.
- **Асинхронность.** Независимые запросы — `Promise.all`; без `await` в цикле; без «висящих» промисов (`void` только для осознанного fire-and-forget).
- **Комментарии — «почему», не «что».** По-русски, перед функцией или блоком; код сам говорит «что». JSDoc у экспортов модуля; закомментированного кода нет.
- **Файлы.** Один экспорт-смысл на файл, имя файла — kebab-case и совпадает с главным экспортом (`create-note.ts` → `makeCreateNote`); без barrel-файлов.

Подробно: скил `dev-kit:code-style`.
